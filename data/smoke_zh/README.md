# Chinese clinical-style demo corpus

This folder is a **synthetic** demo, not real patient data:

- `corpus.jsonl` / `qa.jsonl` — hand-written Chinese clinical-style sentences.
- `images/ecg_demo.png` — a synthetic waveform image generated by
  `scripts/make_demo_image.py`, used only to exercise the optional Qwen-VL
  captioner end-to-end.

For real data, replace these with de-identified documents and images (with a
`path` field on each image entry), and confirm data handling with your ethics
committee before sending anything to an external API.
